Deferred extractions and what they'd require
--------------------------------------------
The remaining blocks all reference 10+ module-level let bindings each. To
land them cleanly the next round should start by introducing a runtime
state module that owns the genuinely-shared state, then refactor the leaf
modules to import from it. Sketch:

  // js/state/runtime.js
  export const runtime = {
    studyMode: 'vocab', deck: [], originalDeck: [], currentIdx: 0,
    isFlipped: false, shuffled: true, requiredOnly: true,
    directionToGreek: false, spacedRepetition: true,
    activeDeckCount: 0, marks: {},
    selectedKeys: [], currentSession: null,
    globalWordMarks: {}, globalWordProgress: {}, deckStates: {},
    appUsageStats: { /* ... */ }, appProfile: 'vocab_grammar',
    appGamification: { /* ... */ },
    analyticsExpandedChapter: null, analyticsExpandedWord: null,
    // ...
  };

main.js then mutates `runtime.foo` instead of bare `foo` (a global
find-replace, done one binding at a time so the diff is auditable). Once
that lands, the remaining extractions become near-mechanical:

1. js/ui/progress.js — renderProgress, renderReview, returnSeenCardToDeck.
2. js/ui/render.js — renderCard, flipCard.
3. js/ui/selectors.js — the build*Selector + toggle/deselect block
   (~600 lines), since it only reads runtime.selectedKeys and writes to
   runtime.deck/originalDeck via loadDeckFromKeys.
4. js/ui/navigation.js — navigate, markCard, setStudyMode and the toggle
   bar. This is the hottest path; do it last.
5. js/ui/analytics.js — renderAnalyticsOverlay and its compute helpers.
6. js/domain/morphology.js — answerMorphologyChoice, reveal, self-check.

      9. Reload the page — state should restore.
  - DevTools → Application → Service Workers → "Update on reload" +
    "Offline" — verify the smoke path still works offline.


Things to be careful about (carried forward from v54 plan)
----------------------------------------------------------
- Module imports in main.js use bare paths (no `?v=N`); SW matches them
  via `caches.match(req, { ignoreSearch: true })`. New modules under
  `js/ui/` need adding to `APP_SHELL_PATHS` (with the shared `?v=N`).
- `domain/gamification/usageStats.js` already exports the primitives
  main.js wraps in local `accumulate*` helpers — confirm any future
  extraction uses them rather than reintroducing duplicates.
- `state/store.js` already owns STORAGE_KEY, CONSENT_STORAGE_KEY,
  THEME_STORAGE_KEY, PROGRESS_EXPORT_FORMAT etc. Don't shadow them.
- HTML `onclick="setThemeMode('system')"` etc. fires before main.js
  runs (the script is `type="module"`, so it loads async). The current
  code handles this by initializing globals before any onclick can fire
  — keep that invariant.
